IOC INTEL

Threat-intelligence command center

Threat indicators, collected & scored for analyst review.

This command center aggregates C2, malware distribution, and cracked / pirated-software indicators from public threat-intelligence feeds, deduplicates and scores them, and prepares them for manual review and import.

  • Read-only public feeds, advisories and vendor blogs.
  • No response action — nothing is blocked or contained.
  • Analyst in the loop — outputs require human review.

    API & Integrations

    SIEMs and analysts pull the same feed the bot produces — authenticate with an API key.

    Base URL

    Endpoint root. Versioned under /api/v1.

    Authentication

    X-API-Key: …

    Also accepted: Authorization: Bearer or ?apikey=. Scopes: read / write / admin.

    Pull feed — CSV

    Every field a SIEM reference set needs: IOC, type, severity, confidence, category, malware/actor, folders, validation, first/last seen, source, tags.

    Pull feed — JSON

    Sets format=json; returns {"total", "count", "items"}. Works for programmatic ingestion.

    Pull feed — STIX 2.1

    STIX 2.1 indicator bundle with severity, family, actor, sources and folder context.

    Single IOC

    Full record including categories, sources and folder membership.

    Query parameters

    ParamMeaning

    sort, order, limit, offset, formatsorting, pagination, output format (json · csv · stix)
